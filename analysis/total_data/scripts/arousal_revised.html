What changed relative to arousal.Rmd (all deliberate):

  1. Exclusions are computed on ALL words first, then the norms are merged (arousal.Rmd merged first, so exclusions were computed on a reduced item set and the participants differed from the main analysis).
  2. Norms are merged by Word (they are word properties), with a conflict check; the original merge by Word + Experiment dropped 42 words. Set merge_mode <- "strict" to reproduce the original behaviour.
  3. Arousal and valence are mean-centred, so lower-order terms refer to average arousal/valence.
  4. Models use the paper’s random-effects structure (by-participant and by-word Task slopes), falling back to simpler structures only if the larger one is singular. All models use ML so they can be compared.
  5. Task is contrast-coded (TruthCond = -0.5, Valence = +0.5) and Experiment is sum-coded, so interaction terms are averages across experiments, not effects in the reference experiment (Ex1a).
  6. The “combined model” (additive, not nested) is replaced by properly nested comparisons.
  7. Correlations are computed on unique words, not trials.

Runtime: the three-way models with random slopes can take several minutes each.

Models

Models are fit with ML so that likelihood-ratio tests are valid. The random-effects structure is chosen once, using the largest arousal model, and then used for all models so comparisons are like-for-like.

re_terms <- list(
  maximal      = "(1 + Task | ID.true) + (1 + Task | Word)",
  uncorrelated = "(1 + Task || ID.true) + (1 + Task || Word)",
  intercept    = "(1 | ID.true) + (1 | Word)"
)

fit_ml <- function(rhs, re_struct) {
  fml <- as.formula(paste("LogReactionTime ~", rhs, "+", re_terms[[re_struct]]))
  lmer(fml, data = dcen, REML = FALSE,
       control = lmerControl(optimizer = "bobyqa", optCtrl = list(maxfun = 2e5)))
}

rhs <- list(
  base    = "Task * Experiment",
  A0      = "Task * Experiment + cA",
  A       = "Task * Experiment + cA * Task",
  V0      = "Task * Experiment + cV",
  V       = "Task * Experiment + cV * Task",
  AV      = "Task * Experiment + (cA + cV) * Task",
  A_het0  = "Task * Experiment + cA * Experiment + cA * Task",
  V_het0  = "Task * Experiment + cV * Experiment + cV * Task",
  A_full  = "Task * Experiment * cA",
  V_full  = "Task * Experiment * cV",
  AV_full = "Task * Experiment * (cA + cV)"
)

# Choose the random-effects structure using the largest arousal model
m_sel <- NULL
if (is.null(re_struct_override)) {
  for (s in names(re_terms)) {
    m_try <- fit_ml(rhs$A_full, s)
    if (!isSingular(m_try) || s == "intercept") { re_struct <- s; m_sel <- m_try; break }
  }
} else {
  re_struct <- re_struct_override
  m_sel <- fit_ml(rhs$A_full, re_struct)
}
cat("Random-effects structure used for ALL models:", re_struct, "\n")
## Random-effects structure used for ALL models: maximal
models <- list(A_full = m_sel)
for (nm in setdiff(names(rhs), "A_full")) models[[nm]] <- fit_ml(rhs[[nm]], re_struct)

lrt <- function(label, small, big, bracket) {
  a <- anova(models[[small]], models[[big]])
  tibble(bracket = bracket, test = label, small = small, big = big,
         chisq = a$Chisq[2], df = a$Df[2], p = a$`Pr(>Chisq)`[2])
}

Pooled Task x covariate tests

Slopes are averaged equally across experiments. TruthCond - Valence keeps the sign used in the original text.

std_names <- function(df) {
  nm <- names(df)
  nm[grepl("\\.trend$|^estimate$|^emmean$", nm)] <- "est"
  nm[grepl("LCL$|^lower\\.CL$", nm)] <- "lo"
  nm[grepl("UCL$|^upper\\.CL$", nm)] <- "hi"
  nm[grepl("ratio$", nm)] <- "stat"
  names(df) <- nm
  df
}

slopes_pooled <- function(m, var) {
  emt <- emtrends(m, ~ Task, var = var)
  list(slopes   = std_names(as.data.frame(summary(emt, infer = c(TRUE, TRUE)))),
       contrast = std_names(as.data.frame(summary(pairs(emt), infer = c(TRUE, TRUE)))))
}

Heterogeneity across experiments

By-experiment slope differences (TruthCond - Valence). p_holm corrects across the 7 experiments.

slopes_by_exp <- function(m, var) {
  emt <- emtrends(m, ~ Task | Experiment, var = var)
  list(slopes = std_names(as.data.frame(summary(emt, infer = c(TRUE, TRUE)))),
       contrasts = std_names(as.data.frame(summary(pairs(emt), infer = c(TRUE, TRUE)))) %>%
         mutate(p_holm = p.adjust(p.value, "holm")))
}

Task effect after adjusting for arousal (B10)

The key question: does the valence advantage shrink once arousal is accounted for? Effects are Valence - TruthCond on log RT (negative = Valence faster), at average arousal/valence, averaged over experiments.

task_effect <- function(m, label) {
  emm <- emmeans(m, ~ Task)
  std_names(as.data.frame(summary(contrast(emm, list("Valence - TruthCond" = c(-1, 1))),
                                  infer = c(TRUE, TRUE)))) %>%
    mutate(model = label, .before = 1)
}
task_effect_by_exp <- function(m, label) {
  emm <- emmeans(m, ~ Task | Experiment)
  std_names(as.data.frame(summary(contrast(emm, list("Valence - TruthCond" = c(-1, 1))),
                                  infer = c(TRUE, TRUE)))) %>%
    mutate(model = label, .before = 1)
}
