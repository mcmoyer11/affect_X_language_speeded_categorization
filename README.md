# Speeded Categorization Task

Repo for the Speeded Categorization Tasks. Across 7 experiments we manipulated Task, comparing Valence categorization to TruthConditional categorization. Between-subjects, we manipulated four TruthConditional Features, keeping lexical category consistent within each experiment. Thus, experiments 1a-1c tested concrete vs. abstract in verbs, adjectives, and nouns; Experiments 2a and 2b tested physical vs. psychological (verbs)/social (adjectives); Experiment 3 tested animacy in nouns; finally Experiment 4 tested syntactic categorization in nouns vs. verbs.
